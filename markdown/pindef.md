## SPI 

### ICM42688P -- SPI2 -- TIM2
| Output | Pin Number |
|--------|------------|
| CS     | PB12       |
| SCK    | PB13       |
| MISO   | PB14       |
| MOSI   | PB15       |
| INT1   | PA8        |

### W25Q128JV -- SPI1
| Output | Pin Number |
|--------|------------|
| CS     | PA4        |
| SCK    | PA5        |
| MISO   | PA6        |
| MOSI   | PA7        |

## I2C

### BMP388
| Output | Pin Number |
|--------|-----------|
| SDA    | PB7       |
| SCL    | PB6       |

## USART

### NEO-M8N -- USART2

| Output | Pin Number |
|--------|------------|
| RX     | PA10       |
| TX     | PA9        |
