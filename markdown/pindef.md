# Pin Definitions

## SPI 

### ICM42688P
| Output | Pin Number |
|--------|------------|
| CS     | PB12       |
| SCK    | PB13       |
| MISO   | PB14       |
| MOSI   | PB15       |

### W25Q128JV
| Output | Pin Number |
|--------|------------|
| CS     | PA4        |
| SCK    | PA5        |
| MISO   | PA6        |
| MOSI   | PA7        |

## I2C

### BMP388
| Output | Pin Number |
|--------|-----------|
| SDA    | PB7       |
| SCL    | PB6       |

## USART

### NEO-M8N

| Output | Pin Number |
|--------|------------|
| RX     | PA3        |
| TX     | PA2        |

## PWM

| Output | Pin Number |
|--------|------------|
| ESC 1  | PA8        |
| ESC 2  | PA9        |
| ESC 3  | PA10       |
| ESC 4  | PA11       |

## Flashing

| Output | Pin Number |
|--------|------------|
| SWDIO  | PA13       |
| SWCLK  | PA14       |
