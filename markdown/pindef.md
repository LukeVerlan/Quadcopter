# Pin Definitions

## SPI 

### ICM42688P -- SPI2 -- TIM2
| Output | Pin Number |
|--------|------------|
| CS     | PB12       |
| SCK    | PB13       |
| MISO   | PB14       |
| MOSI   | PB15       |
| INT1   | PA8        |

### W25Q128JV -- SPI1
| Output | Pin Number |
|--------|------------|
| CS     | PA4        |
| SCK    | PA5        |
| MISO   | PA6        |
| MOSI   | PA7        |

## I2C

### BMP388
| Output | Pin Number |
|--------|-----------|
| SDA    | PB7       |
| SCL    | PB6       |

## USART

### NEO-M8N

| Output | Pin Number |
|--------|------------|
| RX     | PA3        |
| TX     | PA2        |

## PWM

| Output | Pin Number |
|--------|------------|
| ESC 1  | PB1        |
| ESC 2  | PB10       |
| ESC 3  | PA0        |
| ESC 4  | PA1        |

## Flashing

| Output | Pin Number |
|--------|------------|
| SWDIO  | PA13       |
| SWCLK  | PA14       |

## USB 

| Output  | Pin Number |
|---------|------------|
| USBDm - | PA11       |
| USBDp + | PA12       |

## Telemetry -- USART1
| Output | Pin Number |
|--------|------------|
| RX     | PA10       |
| TX     | PA 9       | 

TX is unused for telemetry
